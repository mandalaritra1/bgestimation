here to declutter `src/bgestimation/` without deleting anything.

- `logs/` — stray `*.log` run logs from fit/ftest/clamp/floor development passes.
- `test_outputs/` — exploratory 2DAlphabet project dirs from clamp-to-data and
  empty-cell-floor scans (`output_clamp_test*`, `output_floor_*`, `output_originput*`).

None of this is needed to reproduce the final 2024 result — the canonical workflow
and plots live under `../analysis2024/`. Safe to delete entirely if you want the
space back (~190 MB).
